# 🎯 ansible-apache-ops-suite

A small project enterprise-ready for automated Apache HTTPD health check, configuration validator, and HTML reporting role using Ansible, Molecule, and GitHub Actions.



## 📋 PREREQUISITES ##
Before executing the playbook: *check_apache.yml*, create an copy of the inventory from the example provided and configure it with your data from your environment.


**Bash**

`cp inventory/hosts.ini.example inventory/hosts.ini`

`nano inventory/hosts.ini`
